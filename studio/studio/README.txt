ShootFlow — commercial photography marketplace + workflow

CONCEPT
  B2B marketplace connecting professional photographers with marketing teams,
  plus a project workspace for brief → book → deliver. Not a portfolio marketplace
  and not “Upwork for photographers.”

  One-liner: Marketing teams find, brief, book, and manage photographers in one place.

PAGES
  index.html              Public homepage
  photographers.html      Search + filters
  photographer.html       Commercial capability profile (Sofia Martins)
  teams.html              For marketing teams
  for-photographers.html  For photographers
  resources.html          Guides and case studies
  brief.html              Multi-step brief (killer feature)
  matches.html            Ranked photographer matches
  project.html            Project workspace
  assets.html             Campaign library + approvals
  dash-team.html          Marketing-team dashboard
  dash-photog.html        Photographer dashboard

PALETTE / TYPE
  Same Studio system: ink, bone, cobalt, butter, lilac. Syne + Hanken Grotesk.

NOTES
  Front-end prototype only. Filters, brief wizard and matching run in the browser.
